# Text Classification Using Machine Learning

## Project Overview
This Information Retrieval project compares four machine learning algorithms for text classification using the 20 Newsgroups dataset.

## Dataset
- Dataset: 20 Newsgroups
- Number of categories: 20
- Task: Multiclass text classification
- Feature extraction: TF-IDF

## Algorithms Used
1. K-Nearest Neighbours (KNN)
2. Decision Tree
3. Support Vector Machine (SVM)
4. Naive Bayes

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Tools and Technologies
- Python
- Google Colab
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Files
- Google Colab notebook
- Dataset CSV
- Algorithm comparison graph
- Confusion matrices

## Conclusion
The four algorithms are evaluated using the same dataset and training/testing split. The best-performing algorithm is selected based on the experimental results.

**Note:** Final performance values and conclusions are based on the actual experiment output.
